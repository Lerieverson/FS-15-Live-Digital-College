# Arrays

Arrays são estruturas de dados que permitem armazenar múltiplos valores em uma única variável.
Cada valor em um array é chamado de elemento, e cada elemento tem um índice associado, que começa em 0.

## Exemplo de criação de um array

```javascript
// Criando um array de números
const numeros = [1, 2, 3, 4, 5, 345];
```

```javascript
// Criando um array de strings
const frutas = ["maçã", "banana", "laranja"];
```

```javascript
// Criando um array misto
const misto = [1, "dois", true, null];
```

# Array

Um array em JavaScript é uma estrutura de dados que permite armazenar
múltiplos valores em uma única variável. Cada valor no array é identificado
por um índice, que começa em 0.

```javascript
let frutas = ["maçã", "banana", "laranja"];
let textos = [
  "Olá, como você está?",
  "Bem-vindo ao JavaScript!",
  "Aprendendo sobre arrays.",
];
let multiplosTipos = [42, "texto", true];
// Resultado:
// [
//   0: 42,
//   1: "texto",
//   2: true
// ]
multiplosTipos[0]; // 42
multiplosTipos[1]; // "texto"
let numeros = [1, 2, 3, 4, 5];
```
